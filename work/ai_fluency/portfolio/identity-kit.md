# Yassin Khodir - portfolio identity kit

AI-assisted deliverable, October 12, 2026. No student work hours are claimed.

## Type
Use one free font: **DejaVu Sans** for both headings and body text.
Fallback: sans-serif. Headings are bold; body text is regular.
Use at least 16 px for body text on the website.

## Palette
| Job | Hex code | Use |
| --- | --- | --- |
| Main | #0F766E | Headings, links, and primary buttons |
| Text | #111827 | Body text |
| Background | #FFFFFF | Main page background |
| Accent | #D97706 | Small decorative details only |

The accent is not used for small text on white. Teal and near-black keep the important text easy to read.
Do not rely on color alone to mark a link, warning, or status.
