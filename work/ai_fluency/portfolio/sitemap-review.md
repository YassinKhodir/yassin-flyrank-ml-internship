## Saved ChatGPT/Codex answer
The three-page map is small enough. Home gives the reviewer a reason to continue. Work supplies the proof. About explains whose work this is and how AI helped.

The weak point is the phrase "give feedback." The reader needs a clear place to do that. Use the existing GitHub pull request as the named route. Say that GitHub sign-in is needed to comment; do not imply there is a contact form or that everyone can comment without an account.

Keep Contact inside About. A separate Contact page would add a step without adding proof. Do not add a blog or a booking page for this review task.

Put each evidence link beside the claim it supports. A general repository link alone makes the reviewer search. The existing Work case sections, evaluation links and demo are the useful route. The calculator demonstrates a small working feature; it does not prove general AI accuracy.

Update the old content-map text that still calls the pages proposed or says no live site exists. That text now conflicts with the public website. Keep "submitted" separate from "approved."

Change to make: name the evidence-to-feedback path in the map, keep About's contact section, and correct the stale build status.
